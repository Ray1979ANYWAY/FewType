# FewType 待办需求（2026-09-12 记录）

## 1. 语音输入翻译流程改造（转写 → 确认 → 翻译）
- 现状：开启「自动翻译」后，转写完成直接翻译上屏，原文没有修改机会。
- 目标：转写完成后**先弹出可编辑文本框显示已采集文字**，用户确认/修改后点击「翻译并上屏」才走翻译上屏。
  - 顺序必须是：转写 → 编辑确认原文 → 翻译 → 上屏（不是先翻译再给编辑）。
- 涉及：
  - 后端：转写完成后不直接翻译，先暂停并把原文推给前端等确认；收到确认后再翻译+上屏。
  - 前端：HUD/面板增加可编辑确认框（交互参考 TTS 版面的「预览翻译」）。

## 2. 翻译目标语言扩展
- 在现有语言基础上增加：西班牙语、法语、德语。
- 涉及：前端语音输入版面目标语言下拉 + 后端翻译语言映射（speech 翻译链路）。
