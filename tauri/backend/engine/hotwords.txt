# VoxEcho ASR 热词文件（语音识别纠偏）
#
# 用法：
#   1. 每行一个词，保存后下次转写自动生效（不用重启）
#   2. 以 # 开头的行是注释，会被忽略
#   3. 最多 500 条；越靠前的词越优先，最常错的放在最上面
#
# 作用：
#   以下词汇在语音中会被优先识别，适合放：人名、地名、品牌、
#   专业术语、以及你发现经常被识别错的词。
#   例：把 "王小波" 放进来，语音里说"王小波"时就不会被识别成"王小勃"。
#
# 注意：
#   模型对热词的利用有上限（约 200 字左右最有效），超出部分会读取不到，
#   所以数量不重要，把最常错的 10~30 个词放最前面效果最好。
#
# 下面的内置示例可直接删除或修改，换成你自己常说的词。
