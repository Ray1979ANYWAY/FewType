  FewType 2.0.1（tkinter 版）使用说明
════════════════════════════════════════

【这是什么】
一个程序免费解决三件事：
  · 语音打字（STT）：说话代替键盘打字
  · 电子书朗读：网页电子书微软音色朗读（需配合浏览器扩展）
  · 长文本转语音（TTS）：文字转语音

【快速开始】
1. 双击运行 FewType-bridge.exe（首次运行自动生成配置）
2. 打开设置，填入 STT 服务的 API key（默认 Groq，可自定义 URL / 模型）
3. 按全局快捷键（默认 Ctrl+Win，可在设置里修改）开始录音说话
4. 松开快捷键，语音自动转成文字并上屏

【安装浏览器扩展】（电子书朗读功能需要）
1. 打开 chrome://extensions（或 edge://extensions）
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹中的 FewType-extension 文件夹
5. 打开支持的电子书网页，点击扩展图标即可朗读

【注意】
· 本程序未签名，Windows SmartScreen / 杀毒软件可能提示风险，
  点击「更多信息 → 仍要运行」或将程序加入白名单即可
· 程序是本地中转，不经过任何第三方中转服务器；
  录音会直接发送给你配置的 STT 服务（Groq / 火山等），
  翻译 / 润色使用你配置的 LLM，均受供应方服务政策影响
· 如果你还安装了 Tauri 版（3.x），请不要与它同时运行，
  两个版本的全局快捷键会互相冲突
