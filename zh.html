FewType 适合谁？

三大场景，三类不同的人。你大概率至少对号入座一个。

🎙️

语音输入——说话代替打字

任意窗口按全局热键（Ctrl+Win 或双击 Ctrl），开口就说、说完上屏，粘贴前自动把焦点切回你原来的窗口。

  • 日常聊天、和 AI 对话——快速表达，省去打字的劳动
  • 在意表达出来的样子——自定义风格，把你的话改写成你想要的口吻
  • 一键翻译上屏——说中文、出英文（支持 8 种目标语言）
📖

电子书朗读——用耳朵代替眼睛

浏览器扩展在页面里把电子书读给你听（Google Play Books、Koodo Reader、EPUB 阅读器等）。不是机器音——分段与合成逻辑都针对连贯性调过。

  • 要自然人声，拒绝机器音
  • 长时间专注看字太累——视觉+听觉双通道，让眼睛歇一歇
  • 通勤、家务、眼睛被占用——碎片时间也能"读"书
🎧

长文本转语音——给创作者

粘贴一长段脚本、选个音色、得到一段自然语音的音频文件。它是个附属功能，但对做口播内容的人是救命稻草。

  • 口播主播——不用再亲自念完很长的对白
  • 给数字人 / 虚拟主播提供音频素材
  • 播客草稿、视频配音、有声书试听、外语听力材料

为什么不用系统自带的那个？

Windows 自带语音输入，Wispr Flow 很精致。FewType 的不同之处在这里。

对比 Windows 自带
所有应用都能用，不只系统文本框——浏览器、终端、聊天窗口、自绘菜单焦点恢复 + 模拟粘贴，光标在哪就落在哪，连系统够不到的应用也能上屏。
对比付费听写（Wispr Flow 等）
免费开源、自带 Key——无订阅、无厂商锁定Groq、火山引擎、DeepSeek 或任意 OpenAI 兼容接口，自己的 Key、自己的成本。
对比纯转写工具
内置风格改写 + 翻译——不只是转写，还帮你写得更好自定义风格（比如电影感散文）、一键翻译、同语言直出跳过 LLM。
对比朗读工具
朗读扩展随应用一起发——一次下载，听写和读书都齐了简/繁音色自动匹配书本文字；长文本转语音覆盖创作者场景。

里面有什么

核心能力，一眼看完。

🔑 自带 Key，本地保存

ASR / LLM / TTS 的 Key 全部自己带，配置只在本地；转写内容绝不进日志、不落盘。

🌍 8 种目标语言

简中/繁中、英语、西语、法语、德语、日语、韩语——说一种，出另一种。

⚡ 同语言直出

说中文出中文时不绕 LLM，更快；确认面板只在需要的时候出现。

🧩 扩展随包

Chrome/Edge 电子书朗读扩展，同时兼容新版 Tauri 应用与旧版 TK 线。

开源，也把边界说清楚

FewType 是个人项目，不装成熟团队的门面——这也是它的诚意。

你需要知道的事

  • 要自己申请 API Key。 FewType 是自带 Key（BYOK）模式，ASR / LLM / TTS 服务需要你自己注册。识别与翻译质量取决于你选的服务。
  • 免费、开源（MIT）、无账号、无遥测。 代码、安装包、路线图全部公开。
  • 程序未签名。 Windows SmartScreen 首次运行可能提示，属正常现象，点"更多信息 → 仍要运行"。
  • 由一位开发者维护，通过 GitHub issues 迭代。能力边界由真实使用定义：语音输入、电子书朗读、长文本转语音，各自边界清晰。
🤝 赞助这个项目，就等于给它更多迭代时间。 如果你觉得它有用，你的支持会直接变成维护、新音色、更好的分段逻辑，以及路线图上的新想法。赞助真的会改变这个项目能分到多少时间。
