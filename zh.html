Windows 上的语音输入与语音转文字

任意窗口按下全局热键，开口就说、说完即上屏；可选 AI 翻译与润色，支持 8 种目标语言。配套浏览器扩展还能帮你朗读电子书，简繁体音色自动匹配。

下载 Windows 版 前往 GitHub

一个热键，随处听写

🎙️ 全局语音输入

Ctrl+Win 或双击 Ctrl 全局触发，浏览器、编辑器、聊天窗口、终端——任何能打字的地方都可用。自动上屏并恢复焦点。

🌐 AI 翻译与润色

说一种语言、输出另一种。由 Groq、火山引擎、DeepSeek 或任意 OpenAI 兼容接口驱动的 LLM 翻译与润色；同语言时完全跳过 LLM，直出上屏。

📖 电子书朗读扩展

Chrome/Edge 扩展，在浏览器里把电子书读给你听（Google Play Books、Koodo Reader、EPUB 阅读器等），简体书自动简体音色、繁体书自动繁体音色。

🔒 本地优先、保护隐私

API Key 只存在本地配置；日志仅记录错误，转写内容绝不落盘。无账号、无遥测。
