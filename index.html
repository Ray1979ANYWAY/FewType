Open source — and honest about limits

FewType is an indie project. It doesn't pretend to be a mature team product, and that's part of the deal.

What you should know

  • You bring your own AI key — that's what keeps FewType free. No subscription, nothing bundled. Pick a built-in provider (Groq, Volcengine or SiliconFlow), get a free key, paste it in Settings — about two minutes, with step-by-step guides in each scenario. Your key never leaves your machine.
  • Free, open source (MIT), no account, no tracking. The code, the builds, the roadmap — all public.
  • Not code-signed. The note below explains what to expect on first run.
  • Built and maintained by one developer, driven by real use and GitHub issues. Scope is honest: voice typing, ebook reading, long-text speech.
⚠️ About the Windows first-run warning
FewType is a free, open-source personal project and doesn't yet pay for expensive enterprise code signing. On first install, Windows SmartScreen may show a warning. It's safe: click "More info" → "Run anyway". All your data and keys stay on this machine — the program never records your raw dictation audio.

Voice Typing — talk instead of typing

Press a global hotkey in any app, speak, and your words land exactly where your cursor is. Beyond plain dictation, FewType can rewrite your words in a chosen writing style and translate them into another language before they hit the screen.

🗣️ Dictation that works everywhere

Chat windows, browsers, terminals, documents — one hotkey (Ctrl+Win, or double-press Ctrl) starts recording and your speech is typed where the cursor sits. No switching apps, no copy-paste.

🌍 Speak one language, output another

Say it in Chinese, get English, Spanish, French, German, Japanese or Korean in the text box. The translation goes straight to the screen — no second window to manage.

✍️ Writing styles that reshape your words

Pick a style — e.g. "Karwai Wong" turns an ordinary sentence into a cinematic monologue, "Formal" turns scattered notes into a numbered, professional document. Your voice, your words, your chosen tone.

📄 Messy notes → clean documents

Speak several things at once and the Formal style structures them into numbered points — a sloppy thought becomes a document-ready paragraph.

What you need to do

It's really just two steps. The keys live on your machine and are never bundled with the app.

  1. Install FewType on Windows 10/11 — the installer or the portable ZIP both work.
  2. Get one API key from a provider built into the app. Choose whichever suits you:
    Groq — fast, free tier, works worldwide Volcengine (火山引擎) — best for mainland China SiliconFlow (硅基流动) — best for mainland China
  3. Paste the key in Settings — the app opens the provider dialog automatically the first time you press the hotkey.
  4. Press the hotkey and talk. Dictation, translation and styles all work from that moment on.
💡 Translation and style features use an LLM key from the same provider — the settings dialog will point you to the exact field. No server setup, no configuration file to touch.

Ebook Reading — let your ears do the work

A browser extension reads your ebooks aloud in a natural human voice — sentences flow continuously, no robotic breaks. Works with Google Play Books and Koodo Reader.

How it works: the desktop app runs the AI voice engine; the browser extension grabs the page's book text in one click and streams it to be read aloud.

🗣️ A voice that sounds human, not robotic

FewType uses natural neural voices with tuned sentence segmentation and synthesis, so paragraphs read smoothly and continuously — the way a real narrator would.

👀 Give your eyes a break

Long focused reading tires the eyes fast. Read with your ears during commutes, chores, or any moment your eyes are busy elsewhere.

🌏 Voices that match the book

The reader picks the voice that matches the book's language automatically, so words with multiple pronunciations are read correctly in context.

What you need to do

One install, then load the extension in your browser. That's it.

  1. Install FewType — the FewType-extension folder ships inside the install directory (and inside the portable ZIP).
  2. Load the extension in Chrome or Edge: open chrome://extensions → enable Developer mode → Load unpacked → select the FewType-extension folder.
  3. Run FewType (it acts as the local bridge for the extension).
  4. Open your ebook on Google Play Books or Koodo Reader, click Start Reading in the extension popup — the page starts reading aloud, following along with a highlight.
💡 Don't use ebook reading? Just skip the extension step — nothing else is affected. The reader supports Chrome and Edge; if you only read on one device, load it there once.

Long-Text TTS — scripts into speech

Paste a long script, pick a voice, and get a clean natural-sounding audio file. A companion feature that saves creators hours of recording.

🎙️ From script to audio file

Paste your draft, choose a language and a voice, hit generate — the app splits the text intelligently and synthesizes it into a single audio file in your output folder.

🌍 Auto-translation before speaking

Input and output language differ? FewType translates the text first, then reads it — so you can paste English and get a Spanish voice-over without translating by hand.

🎚️ Voices, speed, volume

Hundreds of neural voices across many languages, with adjustable speed and volume. Preview before you generate, then export to a file.

What you need to do

It's the quickest scenario — no keys, no extension.

  1. Install FewType and open the Long-Text TTS tab.
  2. Paste your script and pick the output language.
  3. Choose a voice (and speed / volume if you like) — you can preview first.
  4. Generate — the audio file is saved to your folder (the last-used folder is remembered).
💡 Great for: voice-over creators who don't want to record every line, digital presenters, podcast drafts, sample audiobooks, and listening-practice materials. If translation is needed, the app handles it automatically before speaking.
