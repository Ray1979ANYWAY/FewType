# 📖 VoxEcho

一個程式，免費解決語音打字、電子書朗讀與長文本轉語音。

### 💡 初衷

做這個專案的起因，是我讀電子書時的一個需求：用文字和聲音雙通道輸入，理解更專注，閱讀時間也更長；中途被打斷（比如去倒杯水）也不會斷了思路。

但各家電子書平台的朗讀支援都不太理想，而微軟公共 TTS API 的朗讀品質相當不錯——於是第一版我先做了一個電子書朗讀的 Chrome 擴充功能（需要在電腦網頁端閱讀電子書）。因為想走本地中轉，我又在本地跑了一個後端程式。

後來，我和 AI 的對話、寫作都需要高強度的語音轉文字，乾脆把兩個功能合而為一，只執行一個程式。最後就做成了一個語音平台，包含三個模組：

- **電子書朗讀擴充功能中轉**：網頁電子書朗讀，接入微軟免費音色
- **STT 語音打字**：用語音代替鍵盤輸入（預設使用 Groq API）
- **TTS 文字轉語音**：長文本轉語音

其中電子書朗讀和 TTS 使用微軟免費音色，STT 預設使用 Groq API；也支援自訂 API key、URL 和模型。在個人使用強度下，這些服務基本都免費。

專案共有兩個版本：
- **2.0 版**：基於 tkinter，輕量精簡
- **3.0 版**：基於 Tauri，體驗更現代

### 🌟 核心特性

- 語音打字（STT）：用語音代替鍵盤輸入
- 電子書朗讀：網頁電子書微軟音色朗讀
- 長文本轉語音（TTS）：文字轉語音

### ⚠️ 能力邊界與依賴

VoxEcho 是本地中轉程式，本身不依賴雲端伺服器，但以下能力依賴外部服務，會受其可用性與政策影響：

- **電子書朗讀 / TTS**：使用微軟免費音色服務。微軟可能調整介面、限流或變更服務政策，屆時相關功能可能受影響
- **STT 語音轉文字**：預設使用 Groq API，需要你提供 API key；供應方的定價、限流和模型調整都可能影響使用
- **翻譯 / 潤飾 / 風格化**：使用你在設定中配置的 LLM（如 Groq、火山引擎等），同樣受供應方 API 影響

本專案由個人維護，能力有限，但會盡力維護。遇到問題或想提建議，歡迎在 [issue](https://github.com/Ray1979ANYWAY/VoxEcho/issues) 中提交。

### 🛡️ 未簽名說明

VoxEcho 尚未進行程式碼簽名，安裝和使用時可能遇到以下情況：

- **Windows SmartScreen**：首次執行時可能提示「Windows 已保護您的電腦」（不明發行者）。點擊「更多資訊」→「仍要執行」即可
- **防毒軟體誤報**：未簽名程式可能被 Windows Defender 或其他防毒軟體誤報。可將程式加入白名單後再執行
- **瀏覽器擴充功能**：擴充功能未上架 Chrome 應用程式商店，需要手動載入（開發者模式）；瀏覽器可能提示風險，屬正常現象

專案原始碼開源（MIT 協議），你可以自行審查程式碼後放心使用。
