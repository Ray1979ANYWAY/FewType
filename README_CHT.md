# 📖 VoxEcho - 網頁版電子書朗讀擴充功能

VoxEcho 是一款專為 Chrome 瀏覽器打造的免安裝（綠色版）電子書輔助朗讀工具，支援在網頁端閱讀時提供高品質的語音朗讀體驗。

### 💡 為什麼用 VoxEcho

說真的，現在誰還在電腦上看電子書啊——手機一掏就能看。但如果你真要認真啃一本厚書，電腦的大螢幕、能隨手記筆記、能一邊查資料一邊讀，還是手機比不了的。VoxEcho 做的事很簡單：讓你在電腦上讀書的時候，文字和聲音一起上。

- 讓文字和聲音雙通道輸入——有些句子看著繞，聽一遍就順了；有些段落讀著走神，聽著反而跟得上。
- 可以用舒服的姿勢閱讀。你可以把以前在視覺上投入的專注力放在理解上，閱讀不再是「盯著螢幕」這件事。
- 發音還算自然。用的是微軟 Edge TTS 的神經網路語音，語調斷句都比較順，不是老派 TTS 那種一字一頓的機械音，聽久了也不刺耳。
- 外文書和碎片時間都能用上。中英西日韓五種語言，外文原著不用硬啃；做飯、收拾、通勤的時候讓它播著，厚書不知不覺就聽完了。

### 🌟 核心特性
* **支援平台**：Google Play Books、Koodo Reader、微信讀書（網頁版）。Koodo 自帶 TTS 但免費會員有額度限制，VoxEcho 用微軟 TTS 無額度限制，且在斷句和句間等待上做了最佳化。
* **支援朗讀語言**：中文、英語、西班牙語、日語、韓語。
* **智慧閱讀輔助**：支援頁末自動翻頁，以及高亮文段視覺跟隨（即時同步高亮當前朗讀語句）。
* **快捷控制**：支援使用主鍵盤或小鍵盤的半角句號 `.` 一鍵暫停與恢復朗讀。
