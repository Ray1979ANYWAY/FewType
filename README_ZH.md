# 📖 VoxEcho - 网页版电子书朗读插件

VoxEcho 是一款专为 Chrome 浏览器打造的免安装（绿色版）电子书辅助朗读工具，支持在网页端阅读时提供高质量的语音朗读体验。

### 💡 为什么用 VoxEcho

说真的，现在谁还在电脑上看电子书啊——手机一掏就能看。但如果你真要认真啃一本厚书，电脑的大屏、能随手记笔记、能一边查资料一边读，还是手机比不了的。VoxEcho 做的事很简单：让你在电脑上读书的时候，文字和声音一起上。

- 让文字和声音双通道输入——有些句子看着绕，听一遍就顺了；有些段落读着走神，听着反而跟得上。
- 可以用舒服的姿势阅读。你可以把以前在视觉上投入的专注力放在理解上，阅读不再是"盯着屏幕"这件事。
- 发音还算自然。用的是微软 Edge TTS 的神经网络语音，语调断句都比较顺，不是老派 TTS 那种一字一顿的机械音，听久了也不刺耳。
- 外文书和碎片时间都能用上。中英西日韩五种语言，外文原著不用硬啃；做饭、收拾、通勤的时候让它播着，厚书不知不觉就听完了。

### 🌟 核心特性
* **支持平台**：Google Play Books、Koodo Reader、微信读书（网页版）。Koodo 自带 TTS 但免费会员有额度限制，VoxEcho 用微软 TTS 无额度限制，且在断句和句间等待上做了优化。
* **支持朗读语言**：中文、英语、西班牙语、日语、韩语。
* **智能阅读辅助**：支持页末自动翻页，以及高亮文段视觉跟随（实时同步高亮当前朗读语句）。
* **快捷控制**：支持使用主键盘或小键盘的半角句号 `.` 一键暂停与恢复朗读。
