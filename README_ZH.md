# 📖 FewType

一个程序，免费解决语音打字、电子书朗读与长文本转语音。

### 💡 初衷

做这个项目的起因，是我读电子书时的一个需求：用文字和声音双通道输入，理解更专注，阅读时间也更长；中途被打断（比如去倒杯水）也不会断了思路。

但各个电子书平台的朗读支持都不太理想，而微软公共 TTS API 的朗读质量相当不错——于是第一版我先做了一个电子书朗读的 Chrome 扩展（需要在电脑网页端阅读电子书）。因为想走本地中转，我又在本地跑了一个后端程序。

再后来，我和 AI 的对话、写作都需要高强度的语音转文字，干脆把两个功能合二为一，只运行一个程序。最后就做成了一个语音平台，包含三个模块：

- **电子书朗读扩展中转**：网页电子书朗读，接入微软免费音色
- **STT 语音打字**：语音代替键盘输入（默认使用 Groq API）
- **TTS 文字转语音**：长文本转语音

其中电子书朗读和 TTS 使用微软免费音色，STT 默认使用 Groq API；也支持自定义 API key、URL 和模型。在个人使用强度下，这些服务基本都免费。

项目共有两个版本：
- **2.0 版**：基于 tkinter，轻量精简
- **3.0 版**：基于 Tauri，体验更现代

### 🌟 核心特性

- 语音打字（STT）：语音代替键盘输入
- 电子书朗读：网页电子书微软音色朗读
- 长文本转语音（TTS）：文字转语音

### ⚠️ 能力边界与依赖

FewType 是本地中转程序，本身不依赖云服务器，但以下能力依赖外部服务，会受其可用性与策略影响：

- **电子书朗读 / TTS**：使用微软免费音色服务。微软可能调整接口、限流或变更服务策略，届时相关功能可能受影响
- **STT 语音转文字**：默认使用 Groq API，需要你提供 API key；供应方的定价、限流和模型调整都可能影响使用
- **翻译 / 润色 / 风格化**：使用你在设置中配置的 LLM（如 Groq、火山引擎等），同样受供应方 API 影响

本项目由个人维护，能力有限，但会尽力维护。遇到问题或想提建议，欢迎在 [issue](https://github.com/Ray1979ANYWAY/VoxEcho/issues) 中提交。

### 🔒 安全与隐私

- **你的 API Key 与风格 Prompt 永不存放在程序目录**——统一保存在 `%APPDATA%\FewType\bridge_config.json`。复制、压缩、移动程序文件夹（或本仓库）都不会带走任何密钥。
- 发布包**不含任何配置文件**；内置安全默认值，首次启动自动生成。
- 打包脚本若检测到配置文件会以系统语言弹出警告并中止，密钥不可能混入发布包。
- **卸载**：运行程序目录下的 `uninstall.bat`（删除本地配置，含 API Key），或手动删除程序文件夹及 `%APPDATA%\FewType`。
