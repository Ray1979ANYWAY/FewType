关于 FewType

FewType 是什么？
FewType 是一款免费开源的 Windows 应用，包含三大场景：语音打字（AI 翻译与自定义文风）、浏览器电子书自然语音朗读、长文本转语音。你说话——文字就被打出来、改写、翻译或用自然嗓音朗读。
FewType 真的免费吗？
是的。采用 MIT 协议免费开源，无订阅、不捆绑 AI 密钥——你自己连接所选的 AI 服务，这正是应用保持免费的原因。
使用 FewType 需要准备什么？
一台 Windows 10/11 x64 电脑，加一个内置服务商的 API 密钥。内置分步指南从下载到第一次语音打字大约 两分钟。
真的是开源的吗？
是的——整个项目在 GitHub 上以 MIT 协议公开，包括发布版与路线图。

语音打字

语音打字怎么用？
在任意应用里按 全局热键（Ctrl+Win，或双击 Ctrl）说话，文字就落在光标所在处——无需切换窗口、无需聚焦输入框。
支持哪些 AI 服务商？
Groq——速度快、有免费额度、全球可用。火山引擎 与 硅基流动——中国大陆用户常用。也支持自定义 API 接口。免费额度通常足够个人使用。
说话时能直接翻译吗？
可以。用一种语言说话，文字以另一种语言上屏——翻译在粘贴进文本框之前完成。
可以自定义写作风格吗？
完全可以。告诉 FewType 你想要的口吻，或让它帮你生成提示词。王家卫风格（电影感独白）和规范记录（编号式正式文档）是内置示例——真正的控制权在你手里。

电子书朗读

支持哪些书和站点？
浏览器扩展支持 Google Play Books、Koodo Reader 和 微信读书（weread.qq.com），使用自然神经网络语音朗读。
朗读器是怎么工作的？
两部分：主程序是 AI 语音引擎，浏览器扩展抓取网页正文并交给主程序朗读。安装两者、打开支持的书、按下开始即可。
朗读声音像机器人吗？
不会——主程序使用神经音色并优化了分段逻辑，朗读连续自然，不是逐字念。

长文本转语音

可以导出音频文件吗？
可以。粘贴长脚本、选择音色、调整语速音量、预览后导出语音音频文件——为口播创作者、数字人、播客草稿和听力练习而生。
朗读前会先翻译吗？
可选。输入与输出语言不同时，FewType 会先翻译再朗读——粘贴英文，得到西班牙语配音，无需手动翻译。

隐私与安全

我的 API 密钥和数据存在哪里？
只存在你的本地电脑。密钥保存在你自己的配置中，不会上传到任何地方。程序从不记录原始录音和转写原文。
为什么首次安装 Windows 会弹警告？
FewType 是免费的个人项目，未购买商业代码签名，SmartScreen 首次运行可能提示。是安全的：点击「更多信息」→「仍要运行」即可。一切都在本机。
